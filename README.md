# Xingyun Wu · Personal website

This static site has two pages: `index.html` introduces Xingyun and shows recent highlights, and `cv.html` displays the September 2026 CV as six scrolling page images in `cv-pages/`. The source PDF is kept outside this public repository.

The site is published through the existing GitHub Pages workflow. The CV page has no PDF viewer or download control. As with any public website, visitors can still save content shown in their browser.

To update the CV, render each page of the new PDF as a 1600-pixel-wide PNG, replace the images in `cv-pages/`, and update the date and page count in `cv.html` as needed. Update homepage highlights in `index.html` at the same time.
